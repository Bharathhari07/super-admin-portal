# Super Admin Enterprise Portal

A multi-tenant administrative portal designed for enterprise SaaS governance, organizational hierarchy management, granular role-based access control (RBAC), subscription lifecycle management, and security compliance auditing.

## Key Modules
- **Global Dashboard & Analytics**: Multi-tenant metrics, resource health, and growth analytics.
- **Tenant & Organization Hierarchy**: Complete tenant lifecycle, Companies, Business Units, Departments, Branches, Cost Centers, and Locations.
- **Access Control & RBAC**: Users, Roles, Permissions, Role-Assignments, and Data Scoping.
- **Platform Settings**: Platform Configuration, Feature Management, Licenses, and Security Policies.
- **Compliance & Monitoring**: Immutable Audit Logs with CSV export, and category-filtered Notifications.

## Tech Stack
- React 18 with TypeScript
- Vite
- Tailwind CSS
- Lucide React & Recharts
- TanStack React Query

## Getting Started
1. npm install
2. npm run dev
3. npm run build
